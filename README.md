# Embedded Software Engineering

A research program of the [Duality Lab](https://davisjam.github.io/), led by
James C. Davis at Purdue University.

Testing, analysis, and verification for embedded software under real constraints. Unit Proofing is the current flagship thrust of this lineage.

This repository hosts the program's project site, published at
<https://davisjam.github.io/embedded-software-engineering/>.

The site is under construction.
